# Exercise 1 - Configuring a Basic Spring Application

## Objective

Configure a basic Spring application using XML configuration.

---

## Technologies Used

- Java 17
- Maven
- Spring Core

---

## Files

- pom.xml
- applicationContext.xml
- BookRepository.java
- BookService.java
- MainApp.java

---

## Spring Concepts Used

- IoC Container
- Dependency Injection
- XML Bean Configuration

---

## How to Run

```bash
mvn compile
mvn exec:java -Dexec.mainClass="com.library.MainApp"
```

---

## Expected Output

```
BookService Bean Initialized
BookRepository Bean Initialized
```
