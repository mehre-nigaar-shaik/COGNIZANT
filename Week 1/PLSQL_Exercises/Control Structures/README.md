# Exercise 1 - Control Structures

## Objective

Implement PL/SQL control structures using loops, cursors and conditional statements.

---

## Scenario 1

Apply a 1% discount on loan interest rates for customers whose age is greater than 60 years.

---

## Scenario 2

Promote customers with a balance greater than $10,000 by setting their IsVIP flag to TRUE.

---

## Scenario 3

Retrieve loans due within the next 30 days and print reminder messages.

---

## Concepts Used

- PL/SQL Blocks
- Cursors
- FOR LOOP
- IF Statement
- UPDATE Statement
- COMMIT
- DBMS_OUTPUT
