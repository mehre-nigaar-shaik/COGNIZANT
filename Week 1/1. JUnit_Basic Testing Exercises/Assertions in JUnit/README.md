# Exercise 3 - Assertions in JUnit

## Objective

Demonstrate the use of different JUnit assertions to validate test results.

---

## Assertions Used

- assertEquals()
- assertTrue()
- assertFalse()
- assertNull()
- assertNotNull()

---

## Technologies Used

- Java
- Maven
- JUnit 4.13.2
