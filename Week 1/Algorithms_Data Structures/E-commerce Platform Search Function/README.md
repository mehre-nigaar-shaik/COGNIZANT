# Exercise 2 - E-commerce Platform Search Function

## Objective
Implement Linear Search and Binary Search algorithms for an e-commerce platform and compare their performance.

## Files
- Product.java
- SearchAlgorithms.java
- TestSearch.java

## Concepts Used
- Big O Notation
- Linear Search
- Binary Search
- Arrays
- Time Complexity

## Time Complexity

### Linear Search
- Best Case: O(1)
- Average Case: O(n)
- Worst Case: O(n)

### Binary Search
- Best Case: O(1)
- Average Case: O(log n)
- Worst Case: O(log n)

## Conclusion
Binary Search is more suitable for large, sorted datasets because it performs faster than Linear Search.
